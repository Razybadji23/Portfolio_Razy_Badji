## Projet phare

### Cartographie des zones humides du parc national de Zakouma et du lac Fitri

Ce projet étudie l'apport de la télédétection à la caractérisation des habitats humides au Tchad à partir d'images Sentinel-2 et de classifications supervisées par Random Forest.

**Parc national de Zakouma — février 2024**

- 20 marigots cartographiés ;
- 3 classes : eau, végétation humide et autres surfaces ;
- précision globale : 93,3 % ;
- coefficient Kappa : 0,90.

**Lac Fitri — 2018 à 2025**

- 8 dates de classification ;
- 5 classes d'habitats humides ;
- précisions globales comprises entre 90,63 % et 96,64 % ;
- coefficients Kappa compris entre 0,88 et 0,95.

Les traitements ont été réalisés principalement avec Google Earth Engine, QGIS et des indices spectraux tels que le NDVI, le NDMI et le MNDWI-2.

Le code du projet est disponible dans le dépôt [Sahel-Wetlands-Remote-Sensing](https://github.com/Razybadji23/Sahel-Wetlands-Remote-Sensing).
